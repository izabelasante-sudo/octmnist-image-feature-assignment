# Dataset source and license

The selected images in `data/selected/` are derived from **OCTMNIST**, part of
MedMNIST v2.

- Project website: <https://medmnist.com/v2>
- Official repository: <https://github.com/MedMNIST/MedMNIST>
- Official archive: <https://zenodo.org/records/10519652>
- License reported by MedMNIST for OCTMNIST: **CC BY 4.0**

The subset contains 500 images selected reproducibly from the official
train/validation/test arrays. `selection_manifest.csv` records each selected
image's original split and index. The original labels and split definitions are
preserved.
